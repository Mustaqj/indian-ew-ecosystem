# Indian EW Ecosystem

An open-source catalogue of 59 Indian electronic warfare and C4ISR systems.

Each entry records the developing agency, prime manufacturer, vendor base, customer
service, platforms fitted, programme status and disclosed contract value, with a named
public source and a confidence grade on every record. Fields that public reporting does
not support are marked "not reported" rather than estimated.

**Sources:** Ministry of Defence and Press Information Bureau releases, DRDO and ISRO
publications, defence public-sector product literature, and established defence trade
press. No classified, restricted or internal material has been used.

Single self-contained HTML file. No build step, no dependencies, no external requests.

Revision 1.0, September 2026.
